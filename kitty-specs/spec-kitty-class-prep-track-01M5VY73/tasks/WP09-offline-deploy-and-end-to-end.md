### Subtask T038 – Service worker

**Steps**:
1. `const CACHE = "skcp-v1";` and a `PRECACHE` list of every shipped file, all relative (`./`, `./index.html`, `./css/style.css`, `./manifest.json`, every `js/**` file, `./icons/*`). Build the list from `git ls-files` at implementation time, excluding `tests/`, `kitty-specs/`, `.kittify/`, `.claude/` and `README.md`. Add a header comment: "Every shipped file must be listed here; bump CACHE on each release."
2. `install`: `caches.open(CACHE).then(c => c.addAll(PRECACHE))`, then `self.skipWaiting()`.
3. `activate`: delete only keys where `key.startsWith("skcp-") && key !== CACHE`. Then `clients.claim()`.
4. `fetch` (GET, same-origin, within scope only):
   - respond from the cache if present, and in the background fetch and update the cache (stale-while-revalidate);
   - on a miss, fetch from the network, put the response in the cache, and return it;
   - if both fail for a navigation, return the cached `./index.html`.
   Ignore cross-origin requests entirely (tool links are navigations away, not fetches).
5. Registration in `js/app.js` at the marked spot:
   ```js
   if ("serviceWorker" in navigator) navigator.serviceWorker.register("./service-worker.js");
   ```
   Log it in the activity log as an out-of-map edit ("WP02 left the marked spot for this").
